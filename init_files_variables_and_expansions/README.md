# Init Files, Variables and Expansions

- 0-alias: creates an alias named ls with the value rm -f *.
- 1-hello_you: prints hello followed by the current user.
- 2-path: adds /action at the end of the PATH.
- 3-paths: counts the directories in the PATH.
- 4-global_variables: lists environment variables.
- 5-local_variables: lists all variables, environment variables and functions.
- 6-create_local_variable: creates a local variable BEST with the value School.
- 7-create_global_variable: creates a global variable BEST with the value School.
